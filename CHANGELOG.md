# Changelog (forthcoming)

This document will track user-visible changes to the project,
organised by release. The forthcoming format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) with
sections for `Added`, `Changed`, `Deprecated`, `Removed`,
`Fixed`, and `Security`. Each entry links to the PR that
introduced the change.

Until the changelog is published, see the commit history and
release tags on GitHub.
