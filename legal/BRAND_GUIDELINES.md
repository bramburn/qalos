# Brand guidelines (forthcoming)

This document will set out the rules for using the project's
trade names and marks on Prebuilt Images, derivative works, and
third-party materials. Until published, contributors and
downstream users must not use the project's trade names in any
manner that suggests endorsement by the project owner or that
disparages the project. See [`TERMS_OF_SERVICE.md`](TERMS_OF_SERVICE.md)
§6 for the binding use restrictions.
